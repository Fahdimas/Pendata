Topik: Implementasi Klasifikasi Naive Bayes (Gaussian) menggunakan KNIME Analytics Platform#

1. Landasan Teori: Naive Bayes#

Naive Bayes adalah algoritma klasifikasi yang berdasar pada Teorema Bayes. Algoritma ini memiliki asumsi bahwa setiap fitur bersifat independen (tidak saling berkaitan) dalam memengaruhi klasifikasi suatu data.

A. Teorema Bayes (Learner)#

Model mempelajari pola data dengan menghitung probabilitas berdasarkan data historis menggunakan rumus:

\[P(C|X) = \frac{P(X|C)P(C)}{P(X)}\]

Keterangan:

  • \(P(C|X)\) : Posterior (Peluang kelas muncul setelah melihat data).

  • \(P(X|C)\) : Likelihood (Peluang data muncul dalam kelas tertentu).

  • \(P(C)\) : Prior (Peluang awal kemunculan kelas).

  • \(P(X)\) : Evidence (Peluang data secara keseluruhan).

2. Varian Gaussian Naive Bayes#

Varian Gaussian digunakan dalam praktikum ini karena fitur-fitur pada dataset bersifat kontinu (numerik), salah satunya adalah fitur BMI (Body Mass Index).

Apa itu BMI? BMI atau Indeks Massa Tubuh adalah ukuran yang digunakan untuk menilai proporsi berat badan terhadap tinggi badan seseorang. Dalam dataset diabetes ini, BMI menjadi variabel kunci karena berat badan berlebih seringkali berkorelasi dengan risiko kesehatan. Karena nilainya berupa angka desimal (kontinu), fitur ini diproses menggunakan varian Gaussian yang mengasumsikan data mengikuti Distribusi Normal.

Rumus Likelihood Gaussian (Predictor)#

\[P(x_i | C) = \frac{1}{\sqrt{2\pi\sigma_C^2}} \exp\left(-\frac{(x_i - \mu_C)^2}{2\sigma_C^2}\right)\]

Keterangan Simbol Rumus:

  • \(P(x_i | C)\): Nilai Likelihood (peluang nilai fitur \(x_i\) pada kelas tertentu \(C\)).

  • \(\pi\) (Pi): Konstanta matematika (\(\approx 3.14159\)).

  • \(\sigma_C^2\) (Varians): Menunjukkan seberapa lebar sebaran data fitur pada kelas tersebut.

  • \(\mu_C\) (Mean): Nilai rata-rata fitur pada kelas tertentu.

  • \(\exp\): Fungsi eksponensial (bilangan Euler \(e \approx 2.718\)).

3. Tahapan Implementasi pada KNIME#

Berikut adalah tahapan inti yang diimplementasikan dalam praktikum ini:

  1. Normalisasi (Z-Score): Menyetarakan skala fitur numerik agar tidak ada fitur yang mendominasi perhitungan probabilitas secara tidak adil.

  2. Table Partitioner (80:20): Membagi dataset menjadi dua jalur port: 80% Training untuk pembelajaran dan 20% Testing untuk pengujian.

  3. Python Scripting: Implementasi algoritma menggunakan library sklearn.naive_bayes.GaussianNB. Kode disesuaikan dengan menggunakan .astype(int) pada label target untuk memastikan kompatibilitas tipe data antara KNIME dan Scikit-Learn.

B. Skor Posterior#

  • Likelihood \(P(33.0|0)\): \(\approx 0.0549\).

  • Likelihood \(P(33.0|1)\): \(\approx 0.0524\).

  • Skor Kelas 0: \(0.0549 \times 0.65 = \mathbf{0.03568}\).

  • Skor Kelas 1: \(0.0524 \times 0.35 = \mathbf{0.01834}\).

Kesimpulan: Karena Skor Kelas 0 lebih tinggi, maka data tersebut diprediksi sebagai Tidak Diabetes (0).
