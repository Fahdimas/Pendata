Topik: Implementasi Klasifikasi & Regresi Random Forest#

Menggunakan KNIME Analytics Platform#

Oleh: Fahdimas Akmal (Dimas)

1. Landasan Teori: Random Forest#

Dalam tugas ini, saya menerapkan algoritma Random Forest, yaitu metode ensemble learning yang membangun banyak pohon keputusan (Decision Trees) secara acak untuk mendapatkan hasil prediksi yang lebih stabil dan akurat.

Beberapa konsep kunci yang saya terapkan adalah:

  • Bootstrapping: Proses pengambilan sampel data secara acak dengan pengembalian untuk melatih setiap pohon individu.

  • Feature Randomness: Setiap pohon hanya melihat subset acak dari fitur yang ada, sehingga pohon-pohon tersebut tidak saling berkorelasi.

  • Majority Voting: Untuk klasifikasi, hasil akhir diambil dari suara terbanyak dari seluruh pohon.

2. Tahapan Implementasi pada KNIME#

Berikut adalah rincian tahapan yang saya lakukan dalam workflow ini berdasarkan screenshot konfigurasi:

A. Konfigurasi Table Partitioner (Data Splitting)#

Pada node ini, saya membagi dataset menjadi dua bagian utama untuk menjamin objektivitas pengujian model.

![image_72245e.png - Screenshot Table Partitioner Settings]

  • Relative Size (80%): Saya menetapkan 80% data untuk Training (pembelajaran) dan sisanya 20% untuk Testing (pengujian).

  • Stratified Sampling: Saya memilih strategi ini pada kolom “Play Tennis” agar proporsi kelas (Yes/No) di data latih dan data uji tetap seimbang, mencegah model menjadi bias.

B. Konfigurasi Random Forest Learner (Model Training)#

Pada node ini, saya menentukan atribut apa saja yang akan dipelajari oleh “hutan” pohon keputusan saya.

![image_7223df.png - Screenshot RF Learner Classification Settings]

  • Target Column: “Play Tennis” (Variabel yang ingin ditebak).

  • Training Attributes: Saya memasukkan fitur Day, Outlook, dan Temp sebagai prediktor.

  • Split Criterion (Gini Index): Saya menggunakan kriteria Gini untuk menentukan seberapa “murni” sebuah cabang pohon.

3. Simulasi Perhitungan Manual (Gini Impurity)#

Untuk memahami bagaimana pohon dalam Random Forest membelah data, saya melakukan perhitungan manual Gini Impurity pada akar pohon (root node) menggunakan dataset “Play Tennis” (14 baris).

Rumus Gini Impurity:#

\[Gini(S) = 1 - \sum_{i=1}^{n} (p_i)^2\]

Keterangan Simbol:

  • \(Gini(S)\): Nilai ketidakmurnian data. Semakin mendekati 0, maka data semakin murni (homogen).

  • \(1\): Melambangkan total probabilitas maksimal.

  • \(\sum\): Simbol penjumlahan untuk seluruh kelas yang ada.

  • \(p_i\): Probabilitas kemunculan kelas \(i\) (Jumlah data kelas \(i\) dibagi total data).

Langkah Perhitungan (Data Keseluruhan):#

Berdasarkan gambar data, terdapat 14 baris data dengan hasil: 9 Yes dan 5 No.

  1. Hitung Probabilitas:

    • \(p_{Yes} = 9/14 = 0.642\)

    • \(p_{No} = 5/14 = 0.357\)

  2. Masukkan ke Rumus:

    • \(Gini(S) = 1 - [(0.642)^2 + (0.357)^2]\)

    • \(Gini(S) = 1 - [0.412 + 0.127]\)

    • \(Gini(S) = 1 - 0.539 = \mathbf{0.461}\)

4. Evaluasi Multi-Scorer#

Saya menggunakan tiga jenis evaluasi untuk melihat performa model dari berbagai sudut pandang:

1. Out-of-Bag (OOB) Scorer#

Scorer ini mengevaluasi model menggunakan data yang tidak terpilih saat proses bootstrapping (validasi internal).

![image_71ca46.png - Screenshot Confusion Matrix OOB]

  • Accuracy: 36.364%. Akurasi ini rendah karena dataset yang digunakan sangat kecil (14 sampel), sehingga model kesulitan melakukan generalisasi secara internal.

2. Scorer Klasifikasi (Data Testing)#

Ini adalah pengujian sesungguhnya menggunakan 20% data yang belum pernah dilihat model.

![image_71cabb.png - Screenshot Confusion Matrix Testing]

  • Accuracy: 66.667%. Dari 3 data uji, 2 berhasil diprediksi dengan benar. Ini menunjukkan performa yang cukup baik untuk dataset skala kecil.

3. Numeric Scorer & Line Plot (Regresi Wind)#

Selain klasifikasi, saya juga melatih model regresi untuk memprediksi nilai numerik “Wind”.

![image_71c9c6.png - Screenshot Numeric Scorer Settings]

Visualisasi di bawah membandingkan nilai Actual (biru) dengan Prediction (ungu/merah). Terlihat adanya selisih (error) yang wajar dalam model regresi.

![image_71c6e3.png - Screenshot Line Plot Regression]

5. Analisis Hasil Akhir#

Dalam tugas ini, saya menyimpulkan bahwa Random Forest memberikan fleksibilitas tinggi karena bisa menangani kasus klasifikasi dan regresi sekaligus. Penggunaan Normalisasi di awal workflow sangat membantu menyetarakan bobot fitur numerik. Meskipun akurasi testing mencapai 66.67%, nilai OOB yang rendah mengingatkan saya bahwa algoritma Random Forest akan jauh lebih maksimal jika digunakan pada dataset yang memiliki jumlah baris ribuan atau lebih.
