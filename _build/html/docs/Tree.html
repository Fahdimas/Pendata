2. Rumus-Rumus Utama#

Algoritma C4.5 menggunakan kriteria Gain Ratio untuk menentukan pembagian data yang paling optimal.

A. Entropy#

Mengukur tingkat ketidakpastian atau “kekacauan” dalam dataset. $\(Entropy(S) = \sum_{i=1}^{c} -p_i \log_2 p_i\)$

B. Information Gain#

Menghitung penurunan nilai entropy setelah dataset dibagi berdasarkan atribut tertentu. $\(Gain(S, A) = Entropy(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} Entropy(S_v)\)$

C. Split Info & Gain Ratio#

Digunakan untuk menormalisasi Information Gain agar tidak bias terhadap atribut yang memiliki banyak nilai unik. $\(SplitInfo(S, A) = - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} \log_2 \left( \frac{|S_v|}{|S|} \right)\)\( \)\(GainRatio(S, A) = \frac{Gain(S, A)}{SplitInfo(S, A)}\)$

3. Perhitungan Manual (Langkah demi Langkah)#

Langkah 1: Menghitung Entropy Total (Root) Total Data: 14 (9 Yes, 5 No). $\(Entropy(Total) = \left( -\frac{9}{14} \log_2 \frac{9}{14} \right) + \left( -\frac{5}{14} \log_2 \frac{5}{14} \right) = 0.9403\)$

Langkah 2: Menghitung Nilai Atribut “Outlook” Atribut Outlook memiliki 3 nilai: Sunny (5 data), Overcast (4 data), dan Rain (5 data).

  • Sunny (2 Yes, 3 No): $\(Entropy(Sunny) = \left(-\frac{2}{5} \log_2 \frac{2}{5}\right) + \left(-\frac{3}{5} \log_2 \frac{3}{5}\right) = 0.9710\)$

  • Overcast (4 Yes, 0 No): $\(Entropy(Overcast) = 0\)$

  • Rain (3 Yes, 2 No): $\(Entropy(Rain) = \left(-\frac{3}{5} \log_2 \frac{3}{5}\right) + \left(-\frac{2}{5} \log_2 \frac{2}{5}\right) = 0.9710\)$

Information Gain (Outlook): $\(Gain(Outlook) = 0.9403 - \left[ \left(\frac{5}{14} \times 0.9710\right) + \left(\frac{4}{14} \times 0\right) + \left(\frac{5}{14} \times 0.9710\right) \right] = 0.2467\)$

Split Info (Outlook): $\(SplitInfo(Outlook) = -\left[ \left(\frac{5}{14} \log_2 \frac{5}{14}\right) + \left(\frac{4}{14} \log_2 \frac{4}{14}\right) + \left(\frac{5}{14} \log_2 \frac{5}{14}\right) \right] = 1.5774\)$

Gain Ratio (Outlook): $\(GainRatio(Outlook) = \frac{0.2467}{1.5774} = 0.1564\)$

Analisis Struktur Pohon:

  1. Outlook terpilih sebagai akar (Root Node).

  2. Jika Outlook = Overcast, maka hasil mutlak adalah Yes.
