UTS PENAMBANGAN DATA#

Laporan Analisis Klasifikasi Kesuburan Tanah#

Metode: K-Nearest Neighbors (KNN)
Tools: KNIME Analytics Platform Penyusun: Fahdimas Akmal

1. Pendahuluan#

Laporan ini disusun untuk mendokumentasikan proses klasifikasi tingkat kesuburan tanah menggunakan dataset agronomis. Dataset ini terdiri dari 2.000 sampel dengan 10 fitur utama (seperti pH, unsur hara NPK, tekstur tanah, dan kerapatan). Target klasifikasi dibagi menjadi dua kelas: Subur dan Tidak Subur.

link File Dataset : https://hackmd.io/@jAmaXS8iRwyGXIDziXEPlw/ryewWKrpWx

Gambaran Awal Dataset (Masalah Data)#

Saat pertama kali data diimpor ke KNIME, ditemukan bahwa data tersebut tidak sempurna. Ada banyak nilai kosong (missing values) yang ditandai dengan tanda tanya (?). Masalah inilah yang menjadi tantangan utama yang harus diselesaikan pada tahap preprocessing.

Keterangan: Screenshot tampilan awal data di KNIME yang menunjukkan adanya nilai kosong (bolong-bolong) pada beberapa fitur.

2. Pemrosesan Data (Preprocessing)#

Tahap preprocessing sangat menentukan akurasi model KNN karena algoritma ini sangat sensitif terhadap skala data dan data yang hilang.

2.1 Penanganan Data Hilang (Missing Value)#

Dataset awal memiliki beberapa nilai kosong. Saya menggunakan node Missing Value dengan konfigurasi:

  • Fitur Numerik: Diisi dengan nilai Mean (rata-rata).

  • Fitur Kategorikal: Diisi dengan Most Frequent Value (modus).

Keterangan: Screenshot jendela konfigurasi penanganan missing value di KNIME.

2.2 Transformasi & Normalisasi#

  • Encoding (One to Many): Fitur ‘Tekstur Tanah’ diubah menjadi kolom numerik.

  • Normalizer (Min-Max): Seluruh fitur numerik disamakan skalanya ke rentang 0-1. Tanpa normalisasi, fitur dengan angka besar akan mendominasi perhitungan jarak Euclidean.

2.3 Pembagian Data (Table Partitioner 70/30)#

Data dibagi secara acak menggunakan node Table Partitioner dengan rasio:

  • Data Training (70% - 1.400 baris): Basis pengetahuan bagi model untuk mengenali pola kesuburan.

  • Data Testing (30% - 600 baris): Data “ujian” yang belum pernah dilihat model untuk memvalidasi akurasi.

Keterangan: Screenshot hasil pembagian data 1.400 baris (training) dan 600 baris (testing).

3. Alur Kerja (Workflow) KNIME#

Seluruh proses dilakukan secara visual menggunakan aliran node di KNIME Analytics Platform.

Keterangan: Screenshot seluruh rangkaian node dari Excel Reader hingga Scorer (Pastikan semua node berwarna HIJAU).

5. Landasan Teori & Perhitungan Manual#

Metrik di atas dihitung berdasarkan rumus matematika berikut (dengan \(TP=296, TN=304, Total=600\)):

  1. Accuracy: $\(\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} = \frac{296 + 304}{600} = 1.0\)$

  2. Precision: $\(\text{Precision} = \frac{TP}{TP + FP} = \frac{296}{296 + 0} = 1.0\)$

  3. Recall: $\(\text{Recall} = \frac{TP}{TP + FN} = \frac{296}{296 + 0} = 1.0\)$

  4. F1-Score: $\(F1\text{-Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = 1.0\)$

6. Kesimpulan#

Berdasarkan eksperimen yang dilakukan, algoritma KNN dengan nilai k=5 dan normalisasi Min-Max terbukti sangat akurat dalam melakukan klasifikasi kesuburan tanah. Penggunaan rasio 70/30 pada Table Partitioner memberikan hasil validasi yang meyakinkan bahwa model mampu membedakan pola agronomis secara sempurna pada data baru.
