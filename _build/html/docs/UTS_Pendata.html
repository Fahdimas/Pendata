Laporan Analisis Klasifikasi Kesuburan Tanah#

Metode: K-Nearest Neighbors (KNN)
Tools: KNIME Analytics Platform
Penyusun: Fahdimas Akmal (Teknik Informatika - UTM)

1. Pendahuluan#

Laporan ini membahas mengenai klasifikasi kondisi kesuburan tanah berdasarkan 10 fitur agronomis. Dataset terdiri dari 2.000 sampel data yang dibagi menjadi dua kelas: Subur dan Tidak Subur. Analisis dilakukan menggunakan algoritma K-Nearest Neighbors (KNN) untuk memprediksi tingkat kesuburan berdasarkan kemiripan fitur-fitur kimia dan fisik tanah.

2. Pemrosesan Data (Preprocessing)#

Langkah-langkah yang dilakukan untuk memastikan data siap diolah oleh model adalah sebagai berikut:

  • Excel Reader: Mengimpor dataset mentah sebanyak 2.000 baris data.

  • Missing Value: Pengisian data kosong menggunakan Mean untuk fitur numerik dan Most Frequent Value untuk fitur kategorikal.

  • One to Many: Transformasi fitur ‘Tekstur Tanah’ menjadi format numerik agar dapat dihitung jaraknya oleh algoritma KNN.

  • Normalizer: Menggunakan Min-Max Normalization (skala 0 hingga 1). Langkah ini wajib dalam KNN agar fitur dengan rentang nilai besar (seperti P Tersedia) tidak mendominasi fitur dengan rentang kecil (seperti pH).

  • Domain Calculator: Digunakan untuk mendefinisikan nilai kategori pada kolom ‘Label’ (Subur/Tidak Subur).

  • Table Partitioner (70/30 Split): Dataset dibagi menjadi dua bagian:

    • Data Training (70% - 1.400 baris): Digunakan agar model mempelajari pola data.

    • Data Testing (30% - 600 baris): Digunakan sebagai data “ujian” untuk mengukur akurasi model pada data baru.

Keterangan: Screenshot seluruh alur node KNIME yang digunakan, pastikan semua node berwarna hijau.

Rumus & Pembuktian Manual:#

Dengan \(TP = 296\) dan \(TN = 304\) (Total Data Uji = 600):

  1. Accuracy: $\(\frac{TP + TN}{Total} = \frac{296 + 304}{600} = 1.0\)$

  2. Precision: $\(\frac{TP}{TP + FP} = \frac{296}{296 + 0} = 1.0\)$

  3. Recall: $\(\frac{TP}{TP + FN} = \frac{296}{296 + 0} = 1.0\)$

  4. F1-Score: $\(2 \times \frac{P \times R}{P + R} = 2 \times \frac{1 \times 1}{1 + 1} = 1.0\)$

5. Kesimpulan#

Algoritma KNN sangat efektif dalam mengklasifikasikan kesuburan tanah dengan tingkat akurasi mencapai 100%. Penggunaan Table Partitioner 70/30 memastikan bahwa model diuji pada 600 data independen, dan hasil sempurna ini menunjukkan bahwa fitur-fitur agronomis dalam dataset memiliki pola pembeda yang sangat jelas antara kondisi tanah subur dan tidak subur.
